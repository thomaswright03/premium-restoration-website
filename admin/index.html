    Data handling and tax: what the owner must do

    Data handling: quotes contain homeowners' property addresses and, if entered, customers' names and contact details. They are saved only in this browser, so export a backup regularly and keep the file somewhere other than this browser; backup files hold the same personal details, so delete old ones in the monthly clean-up. Delete quotes that didn't become jobs after about a month (30 days; the public Privacy Notice says enquiries are kept for about a month), mark quotes that became jobs as booked so they are kept, and delete a quote promptly if the homeowner asks. The clean-up record above is kept only in this browser, so also note each clean-up in the business's own records. Tax on labor: the tax rate defaults to 0% — only change it under Business Prices once a tax adviser confirms tax applies.

    Business Prices

    A flat $ price per unit for each item — not hours x rate. Set them once here and every bathroom quote uses them. These are labor prices only; materials are never included.

    The public website shows its own published prices (for example $60 per cabinet and $5 per sq ft of flooring), set in the site's settings file, site-config.json. A price changed here is used only for quotes made in this browser. To change what the website shows, change it in site-config.json instead (README “Site settings”: edit the file on GitHub and commit); the website, the chat and new quotes then all use the new price. The dashboard warns you when a price here differs from the website's.
