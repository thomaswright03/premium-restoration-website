    No quotes in this browser. Choose "Create New Quote" to get started, or "Restore from Backup" to bring back quotes from a backup file.

    Data handling: quotes contain homeowners' property addresses and, if entered, customers' names and contact details. They are saved only in this browser, so export a backup regularly and keep the file somewhere other than this browser; backup files hold the same personal details, so delete old ones in the monthly clean-up. Delete quotes that didn't become jobs after about a month (30 days; the public Privacy Notice says enquiries are kept for about a month), mark quotes that became jobs as booked so they are kept, and delete a quote promptly if the homeowner asks. The clean-up record above is kept only in this browser, so also note each clean-up in the business's own records.
